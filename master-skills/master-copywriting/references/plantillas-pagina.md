# Plantillas Editoriales por Tipo de Página

## Páginas de negocio y contenido

| Tipo de página | Objetivo editorial | Secuencia de secciones recomendada |
|---|---|---|
| **Home** | Posicionar la marca y enrutar por intención | Hero (propuesta de valor + CTA) → Panorama de servicios enlazados → 3–5 diferenciadores → Prueba social → Cobertura/alcance → Preguntas frecuentes naturales → CTA final |
| **Landing** | Una sola acción de conversión alineada al tráfico | Hero (titular alineado al anuncio/origen + subtítulo + CTA) → Problema/dolor → 3–5 beneficios → Prueba social → Cómo funciona (3–4 pasos) → Objeciones → CTA final con reversión de riesgo |
| **Service** | Convertir búsquedas de servicio en consultas/reservas | Apertura *answer-first* (qué es el servicio) → Quién lo necesita → Proceso numerado → Rangos o modelo de precios → Resultados/casos → Por qué elegir la marca → FAQ → CTA |
| **Pricing** | Eliminar la duda *"¿cuál plan es para mí?"* | Encuadre por perfil de cliente → Plan recomendado evidente → Comparación clara de inclusiones/límites → Objeciones frecuentes de precio/facturación → Prueba social → CTA |
| **About** | Construir confianza y credenciales E-E-A-T | Quiénes somos (conectado al beneficio del cliente) → Historia verificable con hitos/fechas → Equipo con bios y credenciales → 3–5 valores concretos → Reconocimientos/prensa → CTA |
| **Case Study** | Demostrar resultados reales y transferibles | Resumen de resultado en primera línea → Contexto del cliente → Reto y riesgo → Enfoque paso a paso → Resultados con cifras y plazos → 3–5 aprendizajes → CTA al servicio relacionado |
| **Blog** | Responder intención informativa y derivar a servicios | Respuesta directa *answer-first* (40–60 palabras) → Contexto (1–2 párrafos) → 3–5 H2 profundos cubriendo brechas reales → Errores comunes → FAQ natural → CTA contextual al servicio |
| **Location** | Captar intención `[servicio] + [ciudad]` | Servicio en la ciudad → Zonas, barrios o referencias locales reales → Área de cobertura → Por qué importa la experiencia local → Equipo local → Reseñas mencionando la ubicación → FAQ local → CTA con teléfono/dirección locales |

## Formatos comparativos BOFU

| Formato | Intención de búsqueda | Secuencia recomendada |
|---|---|---|
| **`[Rival]` alternativa** (singular) | Usuario evaluando migrar desde un rival específico | Motivos de cambio (validar dolor) → Resumen TL;DR (2–3 oraciones) → Comparativa por criterio (tabla descriptiva + párrafos) → Quién debería cambiar y quién no → Ruta de migración → Testimonios de migrados → CTA |
| **Alternativas a `[Rival]`** (plural) | Usuario explorando 4–7 opciones reales | Motivos de búsqueda → Criterios de evaluación → Lista de 4–7 alternativas reales → Tabla descriptiva resumen → Desglose individual por alternativa → Recomendación por caso de uso → CTA |
| **`[Tú]` vs `[Rival]`** | Comparación directa 1 a 1 | Resumen TL;DR → Tabla descriptiva rápida → Comparativa detallada por categoría (funciones, precios fechados + costes ocultos, soporte, uso, integraciones) → Para quién conviene `[Tú]` → Para quién conviene `[Rival]` → Testimonios → Migración → CTA |
| **`[Rival A]` vs `[Rival B]`** | Comparación entre dos competidores | Panorama de ambos → Comparativa por categoría → Para quién conviene cada uno → Tercera opción (presentación propia) → Tabla descriptiva de las tres opciones → CTA |
