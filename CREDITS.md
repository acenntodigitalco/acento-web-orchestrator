# Créditos y Agradecimientos

**Acento Web Orchestrator** existe gracias al ecosistema open-source de skills, guías de ingeniería y buenas prácticas compartidas generosamente por la comunidad.

Este proyecto es el resultado de auditar, contrastar, depurar contradicciones, corregir errores técnicos, traducir y reescribir desde cero una arquitectura modular propia de **10 master skills** sin solapamientos, mantenida por **Acento Digital by Elkin De Ávila**.

## Áreas e inspiraciones de la comunidad
Agradecemos a todos los autores y equipos que mantienen guías abiertas sobre:
- **Plataforma Web Moderna y Diseño UI/UX:** estándares W3C/MDN Baseline (*Web Platform First*), WCAG 2.2 AA, color OKLCH y diseño editorial anti-genérico.
- **Ecosistema WordPress y WooCommerce:** documentación oficial de WordPress Core, Block Themes (`theme.json` v3), Interactivity API, WP-CLI, PHPStan para WordPress y WooCommerce HPOS / Checkout Blocks.
- **Astro y Frontend moderno:** documentación de Astro 5/6, arquitectura de islas y CSS moderno / Tailwind v4 / Bootstrap 5.3.
- **SEO Técnico y GEO/AEO 2026:** RFC 9309, documentación de Google Search Central, Schema.org, Core Web Vitals y estándares abiertos para búsqueda agéntica.
- **Conversión (CRO), Copywriting y Analítica:** principios estadísticos de la ASA para experimentación A/B, escritura directa basada en Voz del Cliente (VoC), Consent Mode v2 y medición orientada a negocio.
- **Animaciones Web:** Web Animations API (WAAPI), CSS Motion y GSAP ScrollTrigger.

Si deseas proponer mejoras, reportar un error técnico o sumar un nuevo perfil al instalador, abre un *Issue* o *Pull Request* en este repositorio.
